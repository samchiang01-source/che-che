# 車車出動

給 3 歲小孩的車車互動網頁。垃圾車、水泥車、消防車、卡車、高鐵、輕軌，點一下就出動，而且會開到現場做自己的工作。

- **玩的頁面** — `docs/index.html`
- **給家長的內容建議** — `docs/guide.html`

## 設計前提

3 歲的限制決定了全部的設計：**不識字、手指不精準、注意力 1~3 分鐘、愛重複**。所以：

| 項目 | 做法 |
|---|---|
| 文字 | 幾乎不出現，用圖示加語音 |
| 按鈕 | 至少 80×80px，間距要大 |
| 操作 | 只有「點一下」，沒有拖曳、雙擊、長按 |
| 失敗 | 沒有錯誤狀態，選錯就再試 |
| 音效 | 一定要有，但留靜音鍵給家長 |
| 關卡 | 不計時、不計分、沒有排行榜 |

## 互動只有兩層

1. **點下面的按鈕** → 那台車開出來，語音念出車名。
2. **點畫面上的車** → 它開到工作現場、停下來、把工作做完，語音講出它在做什麼，然後繼續開。

每台車都有自己的工作，這樣小孩認的就不只是外型，而是「這台車是做什麼的、為誰做的」。

三個原則：

1. **東西要真的進到車子裡**，而且車子看得出來不一樣了 —— 光讓東西消失，小孩不知道發生了什麼事。
2. **要有人**。東西不會自己飛，是人撿起來、遞出去、交給另一個人。
3. **要演到「為了誰」**。工作做完，字幕換成這件事跟大家生活的關係，小孩和現場的人互相揮手。

| 車 | 完整的一段故事 | 車子/現場的變化 |
|---|---|---|
| 垃圾車 | 清潔隊員撿起袋子甩進車尾 → 收滿了 → **開到垃圾處理場掀斗倒掉** | 車斗一袋一層堆高，最後整車倒進坑裡 |
| 水泥車 | 工人把砂石裝進滾筒 → 水泥送到工地 | 滾筒裝滿，工地**一層一層長出一棟大樓**（地基→一樓→二樓→三樓→屋頂水塔） |
| 消防車 | **消防隊員跑出來拉水線** → 兩道水柱澆上屋頂 | 火分段熄滅、窗戶橘光轉藍、冒白色水蒸氣 |
| 卡車 | 送貨員從車上搬下來 → **交到店員手上** → 上架 | 店裡櫥窗擺滿商品 |
| 高鐵 | 在城市車站上車 → 開車 → **窗外的高樓變成稻田** → 到站下車 | 車窗坐滿乘客，景色從城市換成鄉下 |
| 輕軌 | 在商店街上車 → 開車 → **經過紅綠燈到公園** → 到站下車 | 車窗坐滿乘客，街景從商店街換成公園 |
| 飛機 | 旅客拉行李登機 → 起飛爬升 → **飛越大海** → 降落在另一個國家 | 機窗坐滿乘客，遠方浮現該國地標 |

每段結束時字幕會換成第二句，講出這件事對大家的意義（例如「謝謝垃圾車，我們住的地方才乾淨」），同時小孩和工作的人互相揮手，車子鳴笛開走。

工作做完後現場會復原，所以可以一直重複玩 —— 這正是 3 歲最吃的那一味。

## 技術上值得知道的幾件事

- **沒有任何相依套件**，也沒有建置步驟。`docs/` 就是最終送出去的內容。
- **聲音全部即時合成**（Web Audio API），repo 裡沒有任何音檔。垃圾車放的是《給愛麗絲》，因為台灣的垃圾車就是這樣。
- **旁白用 `speechSynthesis` 念出來**（`zh-TW`），沒有中文語音的裝置會靜靜跳過。畫面上同步顯示同一句字幕，方便家長跟著念。
- **車子是手寫 SVG**，不是圖片，所以任何解析度都清楚。車體一律畫成朝左再用 `scaleX(-1)` 翻面，車頭才會朝向前進方向。
- 開車動畫用 `left` 的 keyframes 跑；要停下來工作時改成 `transition`，工作完再用**負的 `animation-delay`** 把動畫捲回停車的位置接著跑，位置才不會跳。
- 台灣細節：高鐵跑高架橋、輕軌跑草坪軌道、高鐵是 700T 的白底橘線。

## 本機預覽

```bash
node tools/serve.mjs
```

開 <http://localhost:4173/>。這個伺服器只服務 `docs/`，跟線上送出去的內容一致。

## 重新產生 App 圖示

`docs/icons/*.png` 是程式畫出來的，不是設計稿：

```bash
node tools/make-icons.mjs
```

`tools/make-icons.mjs` 用 Node 內建的 zlib 直接寫 PNG，所以不需要 `node_modules`。改圖示請改那支程式，不要直接改 PNG。

## 飛機比較特別

其他六台都是「開到現場、做完、開走」。飛機是唯一會**換一個地方**的：它有垂直方向的移動（起飛爬升、下降落地），中間還有一段場景切換（海面浮現、出發機場退場、目的地地標出現）。

所以 `doJob()` 多了兩個可選欄位：`loadedMs`（車子看得出裝到東西的時刻）和 `doneMs`（工作完成的時刻）。其他車這兩件事同時發生，飛機差了七秒——登機完就看得到窗戶有人，但要飛到別的國家才算完成。飛行編排本身放在飛機自己的 `extra()` 裡，不會動到其他車。

目的地每飛一趟換一個：日本富士山 → 法國鐵塔 → 埃及金字塔 → 澳洲歌劇院。

另外，**帶 `forwards` 的動畫會壓過一般的宣告**。要確實隱藏一個已經在跑動畫的元素，必須連 `animation:none` 一起寫，光寫 `opacity:0` 沒有用——登機完的旅客會浮在海上就是這樣來的。

反過來也有一個坑：**動畫的 `forwards` 只在那條規則還命中的時候有效**。高鐵的景色原本只寫在 `[data-phase="travel"]` 上，一切到 `arrived` 規則就失效，景色整個彈回城市。解法是讓兩個階段共用同一條規則。

## 兩條軌道的沿線景色

側面視角的慣例是「鏡頭跟著車走」：車留在原地，景色往後跑。對 3 歲來說這比讓車開出畫面好懂，也才看得清楚窗外換了什麼。做法是把景色分成兩組，一組在畫面上、一組等在右邊畫面外，開車時一起往左捲 `96vw`。

兩條線經過的東西刻意不一樣，因為它們在真實生活裡就不一樣：

| | 出發 | 途中會看到 |
|---|---|---|
| **高鐵**（長途，城市到鄉下） | 城市車站 | 大樓、一節一節往上收的高塔 → 遠山、稻田、農舍、樹、**水牛** |
| **輕軌**（市區短程） | 商店街 | 麵包店、冰淇淋店、水果店 → 紅綠燈 → **溜滑梯、小狗、長椅、大樹** |

這些都是可以停下來指著問「這是什麼？」的東西——輕軌那一段更是小孩每天在路上真的會看到的。

高架橋上的軌道是用多層 `background-image` 疊出來的：兩條鋼軌、枕木、道床、橋面，各自用 `background-size` 和 `background-position` 定位。

## 檢查 class 有沒有撞名

```bash
node tools/check-classes.mjs
```

垃圾袋原本是 `bag b1`、`bag b2`，後來水泥車工地的地基和牆也叫 `build b1`、`build b2`。CSS 裡工地的規則排在後面，就把垃圾袋的動畫整個蓋掉——袋子站在原地不動，工人對著空氣甩手，而且**畫面上看不出哪裡錯了**，找了好幾輪才發現。

這支工具會抓出「同一個 class 用在不同種類的元素上，而且 CSS 有不帶限定的裸選擇器」的情況。新增任何東西之後都該跑一次。

## 改完之後要蓋版本號

```bash
node tools/stamp.mjs
```

HTML 引用資源時會帶上該檔案內容的雜湊，例如 `assets/play.js?v=38b8058c`。檔案一改雜湊就變，瀏覽器和 CDN 一定會重新抓，不會發生「明明改了卻看不到變化」。沒改的檔案雜湊不變，快取照常有效。

**每次動到 `docs/assets/` 底下的東西，commit 前都要跑一次。**

## 部署

同一份 `docs/` 同時發到兩個地方，內容一樣，兩個網址都能用。**兩邊都是推上 `main` 就自動更新，這個 repo 裡沒有任何 CI 設定檔**——兩個平台各自去拉 GitHub。

| 平台 | 網址 | 誰負責部署 |
|---|---|---|
| GitHub Pages | <https://samchiang01-source.github.io/che-che/> | GitHub 內建，來源是 `main` 分支的 `/docs` |
| Cloudflare | <https://che-che.samchiang01.workers.dev/> | Cloudflare Workers Builds，直接連著這個 repo |

### Cloudflare

Cloudflare 已經把 Pages 併進 Workers，所以這個專案是 Workers 型態的靜態站：設定在 `wrangler.jsonc`，部署指令是 `wrangler deploy`（不是舊的 `wrangler pages deploy`）。

自動部署走 Cloudflare 自己的 Git 整合（Workers Builds），設定在 Cloudflare 後台的 `che-che` Worker → Settings → Build：

| 欄位 | 值 |
|---|---|
| Repository | `samchiang01-source/che-che` |
| Branch | `main` |
| Build command | 留空（這個站沒有建置步驟） |
| Deploy command | `npx wrangler deploy` |

這樣不需要在 GitHub 放任何 API token。要手動部署一次的話：

```bash
npx wrangler deploy
```
